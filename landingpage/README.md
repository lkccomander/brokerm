# Broker Mike Landing

Landing page construida con Vite, React y TypeScript para posicionar a Broker Mike como asesor inmobiliario orientado a inteligencia de mercado y oportunidades premium en Costa Rica.

## Rutas activas

- `/` landing principal
- `/catalogo` catalogo privado
- `/mapa-del-sitio` directorio del sitio

## Stack

- Vite
- React 19
- TypeScript
- Tailwind CSS
- React Router

## Correr el proyecto

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
