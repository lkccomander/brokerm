Crea thumbnails tipo catálogo desde un link público de Instagram o TikTok. La altura queda fija en 288 px para que respete la card real del sitio, y el recorte funciona como object-cover. Si el post es video, puede elegir el frame exacto antes de exportar. Si pega un perfil de Instagram, el tool abre una página de resultados con todos los posts disponibles.
